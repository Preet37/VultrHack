The loop

Four steps, every finding

The same disciplined loop runs on each vulnerability, and nothing is trusted until it has been re-tested.

01 · Find

Read & triage

Agents map the repo on Vultr inference and rank where real vulnerabilities most likely live.

02 · Prove

Confirm in a box

Each candidate is proven inside the disposable machine with a planted canary — a finding is evidence, not a guess.

03 · Patch

Fix a copy

A model writes a fix on a throwaway copy and the original exploit is replayed to check it holds.

04 · Certify

Sign it closed

An independent second model must agree before a re-tested fix earns a signed, replayable receipt.
