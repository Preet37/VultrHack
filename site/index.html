Isolation

A container is not a sandbox

Four tiers of “what dies when the code goes rogue.” Cerberus runs the recommended combo — OpenSandbox on gVisor — on a disposable VX1 you throw away.

01
In-process eval() / subprocess
dies: your app, DB creds, cloud keys
02
Container runc · shared kernel
dies: one kernel bug from tier 1
03
User-space kernel gVisor · syscalls interceptedCERBERUS
dies: the sandbox process
04
microVM Firecracker / Kata · own kernel
dies: the VM — throw it away
